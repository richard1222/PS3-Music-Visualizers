# Project instructions

- Target the built-in PS3 Visual Player only: Gaia, Canyon or Wave. Do not substitute a browser viewer or separate application.
- The active character set is exactly Rin Tohsaka, Saber, Nami, Nico Robin, Hatsune Miku, Rias Gremory and Akeno Himejima. Use artwork containing only these selected characters. Do not expand the roster without a new user instruction.
- Do not call native anime integration complete before it renders inside the built-in music player. Distinguish timed animation from actual audio response.
- Publish no console registry, account data, private deployment receipts, local network addresses, Sony firmware assets, or unlicensed third-party artwork.
- Keep existing different console files intact unless a matching previous deployment receipt authorizes a backed-up update.
- Do not touch trophy data or copy trophy award behavior from the reference project.
- Run the host tests for relevant source changes. Actual console results must be observed separately.
